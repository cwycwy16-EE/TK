# 中文样板图制作 · KAVIO 母版

这是第一阶段：新品资料 → 整套中文样板 → 用户确认。第二阶段读取 ../image-localization/SKILL.md 制作菲律宾、越南版本。沿用已确认的范围、主推色和改图要求，不重复询问；仅做中文无需先问海外市场。

## 母版与素材

母版唯一入口：`D:\跨境美工成品\_固定母版\KAVIO_35630_v1`。先读取母版使用规则.md、reference-manifest.json，并打开对应原图，不能凭记忆套版。运行现有验证：
`& "$env:USERPROFILE\.codex\skills\kavio-template-artwork\scripts\workflow.ps1" -Mode verify`

母版不可访问或哈希变化须报告；用户有意改版另存版本，不能覆盖v1。固定KAVIO绿叶标识、白底深绿浅绿体系、各页结构与文字层级。主图/SKU为1254×1254，详情1086×1448（3:4）；用户明确修改优先。

查看真实商品图，ZIP安全解压至商品独立目录并保留原件。按用户确认、供应商声明、图像可见、推断区分证据，核对SKU、尺寸箭头、材质、五金、开合及配件。母版不提供新品事实。

实际比较候选实拍的清晰度、完整轮廓、主推SKU、关键功能和遮挡，选最适合首图的一张并记录理由。功能型产品可优先用已证实的打开状态，不能凭空生成内部结构。首图产品要足够大，缩略图能辨认包型与功能。

## 文案精简与画面去重（长期规则）

- 采用简洁、干净的商品信息表达。删除装饰性下划线、重复标题、空泛的营销语和低信息副标题；每张图只保留理解商品所需的基础文字。
- 用户指定的颜色名不出现在图片文案中；优先用对应实物色块或商品实拍表达颜色。SKU图如用户要求去掉颜色名称，只保留对应颜色实物，不再叠加颜色名。
- 卖点用事实短语表达。例如有镜子只写“内置镜面/内置镜子”，不添加“整理妆容更容易/更方便”等空泛利益句。不能因精简而删掉用户需要的规格或重要功能。
- 成套图片先建立逐图内容分工。主图与详情页、相邻详情页不得重复使用相同主题和近似构图；特别检查“分区收纳/收纳展示”等主题，确保仅一张承担同一展示任务，其他页面改用不同的已证实特征或场景。
- 最终打包前复核各图文字是否必要、主题/主体画面是否重复；只保留最终通过稿，不把失败稿、旧版或过程稿放进交付目录及压缩包。修订历史可单独留在工作目录，不随最终包交付。
## 整套计划

默认商品根目录 `D:\跨境美工成品\<商品>\母版任务`。已有任务读取workflow.json续接；新任务才运行：
`& "$env:USERPROFILE\.codex\skills\kavio-template-artwork\scripts\workflow.ps1" -Mode prepare -Product "新品名称" -SourceDir "新品素材绝对路径" -OutputDir "新品目录\母版任务"`

初始化14个参考槽位只是准备记录，不是固定交付数量或生成结果。填写每页replacements、evidence、素材、中文文案、尺寸和状态；在独立task-plan.json加入实际SKU页等额外页面，不改变现有脚本槽位含义。

- 主图对应1A首图、A赠品、B尺寸颜色、C功能、D收纳/容量、E细节、F/G/H三张用途场景。赠品仅有新品活动依据才做；无依据标not_applicable，不继承旧品赠品、限量或BUY/GET活动。
- 详情顺序：尺寸信息 → 产品细节 → 收纳展示 → 产品概览 → 使用场景。参数独立成页；未知数字不填，不用0补缺。
- SKU图按本次实际可售颜色制作。8主图+5详情+4SKU=17张只是无赠品四色商品的例子，不能固定套给新品。
- 首图及后续功能、场景统一用已确认主推色；颜色总览与SKU页展示对应真实颜色。主推色缺失只问这一项，同时继续素材核对。不能将历史商品的白色、粉色等设为新品默认。
- 用户要求打开包时锁定对应页面的打开状态，后续版本不得回退。
- 三张场景要有对应环境，如梳妆台、酒店或旅行收纳。产品/人物与环境的光线、透视、比例、接触阴影自然融合，避免贴图感；不强加人物。
- 用户要求整套时完成全部计划页再交付，不停在单张首图等批准。仅用户明确要求先试一张时按单张执行。

## 生图制作与复核

先读取imagegen Skill，逐图查看后用内置image_gen.imagegen编辑/生成中文样板。明确母版图是布局参考、实拍是商品事实参考，传绝对referenced_image_paths，锁定全部中文文字、颜色、结构、五金、实物Logo和配件。

**本流程默认由生图模型完成画面和排版。不能把改渲染代码、程序绘制文字层或模板替换当成生图成品。** 代码仅用于文件管理、哈希、JSON、压缩及不改变构图的尺寸适配。只有用户另行明确指定程序模板制作，才按其新范围处理并如实记录方法。不能因额度、失败或耗时自行降级，也不能用项目旧的“允许模板处理”覆盖本次指定的生图流程。

每次返回立即保存原始生成图、完整提示词、时间和工具输出路径。actual_model无可核验版本时为null，不宣称锁定2.5。逐张检查：

- 外观与实拍一致：包型、开合、口袋、提手/肩带、纹理、Logo、五金和配件不增删、不变形。
- 文案、数字、单位、SKU及尺寸轴语义与证据一致；道具非附送时注明。
- 对照对应母版检查布局：文字不溢出标签/画布、不遮挡商品，标题清晰、正文可读。
- 场景真实有环境、主体完整自然、主推色跨图一致。

每页最多首次加2次针对性修正；失败留过程稿，超限标blocked并继续其他页。工具报错记录真实原因并按提示退避；子智能体额度用尽不等于image_gen额度用尽。不可静默改代码排版或切外部付费API。

## 交付和衔接

每页立即落盘状态和image-provenance.json，不等整套结束才补来源。每条包括output_file、method、source_images、actual_tools、requested_model、actual_model、model_evidence、generation_record、appearance_review、text_review、layout_review、fact_review、limitations、sha256。未查看不得passed。文件数检查不能代替视觉审核。

交付整套中文图片、来源与审核记录及ZIP，报告真实完成数、排除和阻塞。原素材、旧版保留，成品目录只放通过的当前版本。

用户确认后写approved-artwork.json：商品、确认依据（用户消息；时间可知则填）、主推色、SKU/参数证据、scope_version、每页image_id/路径/SHA256/尺寸、已批准局部修改、源provenance路径、目标国家（已知则填）。交付不自动等于批准；用户说“现在继续两国本地化”可作为承接当前中文稿的授权，不重复确认。

交给image-localization的必须是最新确认版本，包括打开包等局部修改。后续修改更新对应哈希，仅重排受影响语言页。制作中文样板本身不授权自动开始外语生成或发布商品。

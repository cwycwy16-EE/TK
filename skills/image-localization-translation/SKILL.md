# 本地化图片翻译

默认交付越南语（VN）和菲律宾英语（PH），用户指定市场时按指定范围。每张输出的唯一默认视觉依据是与它对应的那一张用户原图。每处理一张新图，重新观察并独立描述风格；同一批中也不沿用上一张的字款、配色、装饰或排版。两个语种分别从同一张原图编辑。只有用户在本轮明确指定另一份视觉模板时才使用该模板。首次迁移或工具缺失时读 [新设备使用说明](references/portability.md)。

1. **盘点原图。** 按用户给定顺序逐张打开。记录尺寸、文件名和哈希。区分需要翻译的商品文案、装饰英文和商品本体的印字。包装图中的品牌、场景道具、编号、尺寸线与色卡保留原位。按 [商品保护](references/product-fidelity.md) 核对同 SKU。
2. **定稿译文。** 按 [翻译规则](references/translation-rules.md) 按块记录「原文 → 当地自然短句 → 语义回核」。保留规格、数量与促销条件。用户无需逐句确认。只有影响商品事实的歧义需要询问。
3. **记录原版特征并生图。** 按 [逐张识别与复刻规则](references/layout-rules.md) 确定哪些笔画需要替换，哪些像素应保留。每张原图、每种语言单独调用内置 image_gen.imagegen，以真实原图为编辑输入，由模型直接写最终文字并完成排版。所有新字形均出自模型。禁止用程序写字、代码翻译或以渲染脚本代替生成。生图不可用时说明具体阻塞，不能自动切换到外部付费接口。
4. **锁定原背景。** 只有本轮用户明确要求更换背景时才改背景。保留商品照片、色温、光影、纹理、边框和装饰。模型输出即使肉眼相近，也要检查保护区；若有漂移，用原图像素复原，再做差分。文字检查和差分检查分别执行，不能互相代替。
5. **逐张交付。** 遵循 [验收与来源记录](references/quality-checklist.md)。按原文件名主干分别导出到 VN_越南语、PH_菲律宾英语，尺寸与原图一致，默认 PNG。每个原图与请求市场组合只计一张通过稿。输出 QA_审核记录/translation_review.md、image_quality_report.md 和 image-provenance.json。原图与以前的成品只读。

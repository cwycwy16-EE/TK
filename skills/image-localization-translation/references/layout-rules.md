# 每张图独立识别风格

**先看本张，再定本张。** 每个生成任务只传入本张原图及本张任务确实需要的同款商品证据。商品证据只用于核对外观。此前使用过的测试图、其他商品图、上一页、另一语言的成品都不能充当本张的视觉模板。套图本身一致的部分自然会延续，原本不同的部分分别保留。

## 为本张建立对应关系

1. 打开原图，指出本页要表达什么、阅读顺序是什么，哪些是营销文字，哪些是印在商品或道具上的实物信息。
2. 对每个待译文字块记录原文、位置、相邻元素与实际看见的字体特征。观察粗细、字面宽窄、笔触、倾角、基线、颜色、对齐、占幅和层级。仅记录图中存在的特征。缺少某种装饰时保持缺省，不补造。
3. 标明本张必须保留的背景、商品照片、品牌、图形、构图、色调和留白。文字与图形有叠压时核对遮挡顺序和指向。已有设计性外文按其用途判断是否需要翻译。保持原图实际宽高比例。
4. 在同一文字块写下自然、准确、简洁的目标语表达。若行长改变，先优化表述，再按语义微调断行、字距和占幅；核对重音、小字和阅读顺序。保留必要条件和信息层级，不统一全套字体、背景或装饰。

## 向模型下达本页编辑要求

逐张编写指令，其中的视觉描述必须可以在本张原图上指出对应位置。提供目标语言、每处原文与批准译文的对应关系、希望延续的实际字形特征、编辑边界以及受保护区域。由内置图像模型直接写字、完成排版。禁止把案例的风格词复制成所有页面的默认提示词。用户只说“按上次的方法”时沿用工作方法，视觉还是取自本张原图。

## 背景与验收

始终以解码后的源图为底，保留照片、色温、光影和底纹。允许变化的掩膜应覆盖旧字、新字及必要的抗锯齿边缘，尽量剔除周围空白、装饰和商品细节。旧字覆盖的纯色或渐变可用邻近像素局部还原；复杂纹理用原始无字素材或模型局部修复并复核。无法判断的商品结构标待补。保护区外逐像素核对，另行检查掩膜由谁决定、是否过宽及边缘是否伤及原图。

每张成品只和它自己的原图并排验收。在手机观看尺寸核对第一眼看见的卖点、文字位置及风格；放大核对字形、拼写、促销条件、结构和细节。能在前一张图上找到理由、却不能从本张原图解释的视觉改变，需要返工。
